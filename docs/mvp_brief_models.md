下面是一版 **MVP 对象模型说明（表格版）**，尽量做成可直接用于原型设计和 PRD 的形式。

## 1. 主树对象表

| 层级 | 对象   | 定义                  | 核心职责                  | 主要使用者               | MVP 范围说明                  |
| -- | ---- | ------------------- | --------------------- | ------------------- | ------------------------- |
| 1  | 租户   | 平台中的一级隔离单元          | 隔离组织、数据、权限、配额         | 平台管理员               | MVP 可先单租户实现，但模型保留         |
| 2  | 业务域  | 租户下按业务职能划分的治理单元     | 管理本域场景、域内共享资源、域级规则    | 平台管理员、域管理员          | MVP 先选 1 个业务域验证           |
| 3  | 业务场景 | 面向具体业务目标的交付与使用单元    | 承载业务入口、流程目标、运行观察      | 域管理员、场景负责人、业务用户、开发者 | MVP 的核心对象，业务主要感知这一层       |
| 4  | 智能体组  | 场景下的一套执行编排与协作单元     | 组织多个智能体协作，承接流程执行与发布   | 域管理员、开发者            | MVP 建议一个场景先只做 1 个智能体组     |
| 5  | 智能体  | 组内面向某类任务的最小执行主体  | 负责路由、检索、分析、执行、总结等具体任务 | 开发者                 | MVP 一个智能体组建议 2~4 个智能体    |
| 6  | 资源   | 可被场景、智能体引用的能力资产 | 提供复用能力                | 开发者、域管理员            | MVP 先只做 Skill、MCP、知识库 3 类 |

---

## 2. 资源类型表

| 资源类型      | 定义                  | 典型用途             | 推荐归属       | 推荐绑定对象    | MVP 是否纳入 |
| --------- | ------------------- | ---------------- | ---------- | --------- | -------- |
| Skill     | 平台内封装的具体能力单元        | 调用业务逻辑、执行处理动作    | 智能体组 / 智能体  | 智能体       | 是        |
| MCP       | 通过 MCP 协议接入的外部能力或服务 | 工具调用、系统集成、外部服务接入 | 业务域 / 业务场景 | 智能体       | 是        |
| 知识库       | 可检索和引用的知识资产         | 问答、检索增强、规则参考     | 业务域 / 业务场景 | 智能体       | 是        |
| 数据源       | 外部结构化/半结构化数据接入      | 查询业务数据、上下文补充     | 业务域 / 业务场景 | 智能体组 / 智能体 | 否，后续扩展   |
| Prompt 模板 | 可复用的提示模板            | 统一任务指令、角色设定      | 智能体组 / 智能体  | 智能体       | 否，后续扩展   |
| 规则模板      | 可复用业务规则与校验逻辑        | 决策约束、流程判断        | 业务域 / 业务场景 | 智能体组 / 智能体 | 否，后续扩展   |

---

## 3. 归属与绑定关系表

| 关系类型 | 说明                 | 适用对象                | MVP 处理方式                |
| ---- | ------------------ | ------------------- | ----------------------- |
| 归属   | 表示对象由谁创建、谁维护、谁负责治理 | 资源                  | 必须支持                    |
| 绑定   | 表示对象被谁实际使用         | 资源 → 智能体 / 智能体组 / 场景 | MVP 先以“资源绑定到智能体”为主      |
| 共享   | 表示对象是否允许在一定范围内复用   | 资源                  | MVP 先支持域内共享             |
| 可见性  | 表示谁能看到该对象          | 资源、场景、智能体组           | MVP 先做基础可见范围控制          |
| 可用性  | 表示谁能实际使用该对象        | 资源                  | MVP 可简化为“可见即申请绑定/可直接绑定” |

---

## 4. 配置态与运行态表

| 维度  | 对象     | 作用                 | 产品表现         |
| --- | ------ | ------------------ | ------------ |
| 配置态 | 租户     | 定义隔离边界             | 管理配置页        |
| 配置态 | 业务域    | 定义治理边界             | 域管理页         |
| 配置态 | 业务场景   | 定义业务入口和目标          | 场景详情页        |
| 配置态 | 智能体组    | 定义执行编排单元           | 智能体组配置页      |
| 配置态 | 智能体    | 定义执行角色和能力          | 智能体详情页       |
| 配置态 | 资源     | 定义可复用能力资产          | 资源中心         |
| 运行态 | 任务实例   | 一次业务任务的执行入口        | 任务详情页        |
| 运行态 | 流程实例   | 一次长流程的执行过程         | 流程实例页        |
| 运行态 | 节点状态   | 当前执行到哪一步、节点结果如何    | 流程图/节点列表     |
| 运行态 | 人工介入记录 | 人工补充、审批、终止、重试等动作记录 | 任务/流程详情中的操作区 |

---

## 5. 记忆与知识边界表

| 对象      | 性质       | 放置位置  | MVP 处理方式       |
| ------- | -------- | ----- | -------------- |
| 知识库     | 静态能力资产   | 资源模型  | 作为标准资源类型纳入     |
| 会话上下文   | 运行时上下文状态 | 运行态   | 挂在任务/流程实例上     |
| 智能体记忆策略 | 配置能力     | 智能体配置 | 只做是否启用、是否保留上下文 |
| 长期记忆数据  | 动态沉淀状态   | 横切能力  | MVP 暂不做独立中心    |

---

## 6. 横切模型表

| 横切面    | 定义              | MVP 必须支持            | MVP 暂不展开      |
| ------ | --------------- | ------------------- | ------------- |
| 绑定与共享  | 解决资源非单一从属、可复用问题 | 资源归属、资源绑定、域内共享      | 跨域共享审批、复杂授权   |
| 运行实例   | 解决长流程运行态表达问题    | 任务实例、流程实例、节点状态、人工介入 | 复杂调度策略、全链路诊断  |
| 版本发布   | 解决发布、追溯、回滚问题    | 草稿、已发布、当前生效版本       | 灰度、分批发布、复杂回滚  |
| 记忆与上下文 | 解决上下文状态表达问题     | 会话上下文、任务执行上下文       | 独立记忆中心、长期记忆治理 |

---

## 7. 角色与主要工作对象表

| 角色    | 主要工作层级          | 主要关注内容          | 是否 MVP 核心角色 |
| ----- | --------------- | --------------- | ----------- |
| 平台管理员 | 租户、业务域          | 租户隔离、域管理、基础治理   | 是           |
| 域管理员  | 业务域、业务场景、资源     | 场景管理、域内资源、运行概况  | 是           |
| 场景负责人 | 业务场景            | 业务目标、任务入口、效果与流程 | 建议纳入        |
| 开发者   | 业务场景、智能体组、智能体、资源 | 构建、绑定、调试、发布     | 是           |
| 业务用户  | 业务场景、任务实例       | 发起任务、查看结果、人工介入  | 是           |

---

## 8. MVP 建模边界表

| 类别      | 纳入 MVP | 说明                     |
| ------- | ------ | ---------------------- |
| 主树层级    | 是      | 租户、业务域、业务场景、智能体组、智能体、资源 |
| 资源类型    | 是      | Skill、MCP、知识库          |
| 运行态     | 是      | 任务实例、流程实例、节点状态、人工介入    |
| 版本概念    | 是      | 先做场景/智能体组级别的基础版本       |
| 记忆能力    | 部分纳入   | 只做上下文，不做独立记忆中心         |
| 权限体系    | 部分纳入   | 只做基础角色权限               |
| 审计体系    | 否      | 后续扩展                   |
| 复杂共享审批  | 否      | 后续扩展                   |
| 多租户复杂治理 | 否      | 模型保留，能力后置              |
| 完整资源市场  | 否      | 后续扩展                   |

---

## 9. 一句话总结表

| 项        | 内容                               |
| -------- | -------------------------------- |
| 主树       | 租户 → 业务域 → 业务场景 → 智能体组 → 智能体 → 资源 |
| 横切面      | 绑定共享、运行实例、版本发布、记忆上下文             |
| MVP 核心目标 | 形成最小可配置、可执行、可观测的智能体中台对象模型        |
