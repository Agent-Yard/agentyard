# 当前对象模型说明

历史上的 MVP 版对象模型已归档到 `docs/progress_record/2026-03-mvp_object_model_baseline.md`。
本文件描述当前仓库正在使用的现行模型。

## 1. 主树对象表

| 层级 | 对象 | 定义 | 核心职责 | 主要使用者 | 当前实现状态 |
| -- | -- | -- | -- | -- | -- |
| 1 | 租户 | 平台中的一级隔离单元 | 隔离组织、数据、权限、配额 | 平台管理员 | 模型保留，当前默认单租户 |
| 2 | 业务域 | 租户下的治理单元 | 管理本域场景、资源和规则 | 平台管理员、域管理员 | 已落地 |
| 3 | 业务场景 | 面向具体业务目标的交付单元 | 承载业务入口、目标与运行观察 | 域管理员、场景负责人、业务用户 | 已落地 |
| 4 | 助手 | 场景下的一套执行编排单元 | 组织 agent、承接发布和运行 | 域管理员、开发者 | 已落地 |
| 5 | 智能体 | 助手内部的最小执行主体 | 路由、检索、分析、执行、总结 | 开发者 | 已落地 |
| 6 | 资源 | 可被助手和智能体使用的能力资产 | 提供可复用能力与版本锚点 | 开发者、域管理员 | 已落地 |

## 2. 资源类型表

| 资源类型 | 定义 | 当前用途 | 推荐绑定对象 | 当前状态 |
| -- | -- | -- | -- | -- |
| Knowledge Base | 可检索的知识资产 | FAQ、规则参考、检索增强 | 助手 / 智能体 | 已落地 |
| Tool | 可被 agent 调用的业务能力单元 | 业务处理、策略判断、外部系统协同 | 智能体 | 已落地 |
| LLM Model | 模型提供方配置 | 推理执行 | 助手 / 智能体 | 已落地 |
| Prompt Template | 提示模板资源 | 统一 system / user prompt | 助手 / 智能体 | 已落地 |

## 3. 归属、绑定与冻结关系

| 关系类型 | 说明 | 当前表现 |
| -- | -- | -- |
| 归属 | 谁创建、谁维护、谁负责治理 | 资源、场景、助手都有稳定归属对象 |
| 绑定 | 谁在实际运行中使用该资源 | agent 绑定和 assistant 默认策略同时存在 |
| 共享 | 是否允许在一定范围内复用 | 当前主要按业务域共享思路组织 |
| 版本锚定 | 运行时具体命中了哪个资源版本 | 助手发布时冻结资源版本锚点 |
| 发布冻结 | 运行时到底读草稿还是读快照 | 当前统一基于 release snapshot 启动 |

## 4. 配置态、发布态与运行态

| 维度 | 对象 | 作用 | 当前表现 |
| -- | -- | -- | -- |
| 配置态 | 业务域 / 场景 / 助手 / 智能体 / 资源 | 维护治理结构和草稿配置 | 控制台配置页与 API DTO |
| 发布态 | Assistant Release | 冻结资源锚点、执行配置和图快照 | 运行时稳定入口 |
| 运行态 | Session | 维护单助手会话上下文 | 会话运行页 |
| 运行态 | Task | 单次业务入口或用户提问 | 任务列表 / 详情 |
| 运行态 | Workflow | 长流程执行实例 | 流程观测页 |
| 运行态 | Node Execution | 节点推进与状态记录 | 节点轨迹 |
| 运行态 | Human Intervention | 人工动作记录 | 人工接管与恢复 |

## 5. 编排模型

| 对象 | 定义 | 当前状态 |
| -- | -- | -- |
| Graph Node | 可执行图中的节点 | 支持 `START / AGENT / HUMAN / END` |
| Graph Edge | 节点之间的路由边 | 支持 `routeKey` 与 `defaultEdge` |
| Human Node Config | 人工节点配置 | 支持标题、说明、预期动作、恢复路由 |
| Execution Checkpoint | 人工暂停恢复锚点 | 已落地 |

## 6. 运行时状态载荷

| 对象 | 作用 | 当前状态 |
| -- | -- | -- |
| AssistantRunSnapshot | API 向 runtime 传递的执行快照 | 已落地 |
| WorkflowStartRequest | workflow 启动输入 | 已落地 |
| WorkflowResumeRequest | 人工恢复输入 | 已落地 |
| WorkflowResult | workflow 当前结果或最终结果 | 已落地 |
| ToolInvocationSnapshot | Tool 调用摘要 | 已落地 |
| ToolOutcomeSummary | Tool 执行结果摘要 | 已落地 |

## 7. 当前边界

| 类别 | 当前状态 | 说明 |
| -- | -- | -- |
| 多租户复杂治理 | 保留边界 | 当前默认单租户 |
| 权限体系 | 部分落地 | 以 mock 认证为主 |
| 审计体系 | 未完整落地 | 仅保留必要结构和记录 |
| 异步观测 | 未完整落地 | API 仍同步等待首个 workflow 结果 |
| 生产级 provider 治理 | 未完整落地 | 仍保留 `demo.local` 演示适配 |

## 8. 一句话总结

当前对象模型可以概括为：

**业务域和业务场景负责治理，助手负责发布与运行锚点，智能体负责节点执行，资源负责能力复用，workflow 负责长流程托管，agent-runtime 负责按图执行。**
